# Villa Caetano

Luxury private villa website in North Goa.

**Live Website:** [https://villacaetano.com](https://villacaetano.com)

---

## About the Project

This is a one-page website for **Villa Caetano**, a luxury private villa located in Siolim, North Goa.  
The site features:

- Hero section with call-to-action
- About section with video
- Filterable photo gallery
- Contact section with Google Map & social links
- Floating WhatsApp button
- Social share functionality

---

## Tech Stack

- HTML5
- CSS3 (Custom + Bootstrap 5)
- JavaScript
- Bootstrap 5
- AOS (Animate On Scroll)
- GLightbox
- Isotope (Gallery filtering)

## How to Edit in the Future

### 1. Change Text Content
- Open `index.html`
- Edit text inside the Hero, About, and Contact sections

### 2. Update Photos
- Replace images inside the respective folders:
  - `assets/img/portfolio/pool/`
  - `assets/img/portfolio/living-dining/`
  - `assets/img/portfolio/kitchen-pantry/`
  - `assets/img/portfolio/bedroom/`
  - `assets/img/portfolio/bathrooms/`
  - `assets/img/portfolio/garden-outdoor/`
  - `assets/img/portfolio/facade-exterior/`

- Keep the same file names (example: `pool-1.jpg`, `living-1.jpg`, etc.)  
  **or** update the image paths in `index.html` if you change the names.

### 3. Change Contact Details
Search for these in `index.html`:
- Phone number
- Email
- Address
- WhatsApp number
- Social media links (Instagram, Facebook, Threads, Airbnb, Staymaster)

### 4. Update Colors / Styling
- Main styles are in: `assets/css/main.css`
- Accent color is controlled by the CSS variable: `--accent-color`

### 5. Edit Gallery Filters
The filter buttons and categories are inside the Gallery section in `index.html`.
