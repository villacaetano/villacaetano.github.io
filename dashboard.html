📊 Button Clicks

View All Events (Book Now + WhatsApp) →
After opening Google Analytics, go to Reports → Engagement → Events. Look for book_now_click and whatsapp_click.

🌍 Visitors by Country

Open User Location Report →
In Google Analytics go to: Reports → User → User attributes → Country

📱 Device Breakdown

Open Device Category Report →
In Google Analytics go to: Reports → Tech → Tech details Then select Device category

💡 Quick Tips

  • Data can take a few hours to appear in Google Analytics
  • Use the date range selector (top right) to see Today / Last 7 days / Last 30 days
  • Click on any event name to see more details (country, device, etc.)
